# Org Structure

- Project Director: достижение результата, координация команды, сроки
- Product Architect: смысл продукта, требования, сценарии, MVP
- System Architect: архитектура, зависимости, интеграции
- Tech Lead: технические решения, декомпозиция разработки
- Developer Backend: backend, API, база, интеграции
- Developer Frontend: dashboard, UX, интерфейс
- QA Auditor: тесты, регрессии, критерии качества
- Security Reviewer: секреты, доступы, безопасность
- Documentation Writer: документация, changelog, owner summary
- Cost Controller: бюджет, лимиты, расходы
- Risk Manager: риски, блокеры, эскалация
