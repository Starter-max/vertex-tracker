# Устав проектной компании Test Agent Company

Миссия: создать рабочий результат по запросу владельца без ручного выбора ролей и досок.

Зачем владельцу: снизить операционную нагрузку и экранное время владельца.

Границы: проектирование, планирование, безопасная разработка, канбан, документация, workroom и эскалации.

Успех: есть структура, команда, канбан, workroom, первые решения и следующий шаг.

Спрашивать владельца: удаление, секреты, внешний доступ, бюджет > $2, production-изменения, массовые изменения БД.
