# Project Company Lifecycle

1. Accept owner request.
2. Classify project type.
3. Create project row.
4. Create `/projects/{pid}-{slug}` tree.
5. Write company charter.
6. Select minimal sufficient roles.
7. Create agent rows and mandate files.
8. Build skill map.
9. Create kanban cards.
10. Create workroom messages/decisions/debates/summaries.
11. Integrate or queue dashboard visibility.
12. Run initial kickoff.
13. Return short CEO-level result.
