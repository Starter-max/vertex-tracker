# Workroom Protocol

Agent messages are structured, not stream-of-consciousness. Required blocks: AGENT, POSITION, REASONING, RISKS, NEED FROM OTHERS, DECISION/PROPOSAL.

Owner commands: `/чат PXX`, `/решения PXX`, `/споры PXX`, `/команда PXX`, `/запусти PXX`, `/пауза PXX`. Natural-language equivalents are routed by Master Router.
