# Agent Roles Library

Core roles: Project Director, Product Architect, System Architect, Tech Lead, Backend Developer, Frontend Developer, QA Auditor, Security Reviewer, Researcher, Documentation Writer, Release Manager, Cost Controller, Risk Manager.

A09 selects minimal sufficient roles by project type. Dashboard/software projects include backend, frontend and security roles. Research projects include Researcher. All projects include director, product, architecture, QA, cost and risk coverage.
